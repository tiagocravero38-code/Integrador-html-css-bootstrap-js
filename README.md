## Qué es

Sitio de tres páginas que integra los temas de las primeras clases de la materia:
estructura HTML semántica, hoja de estilos propia, maquetación con Bootstrap 5
y JavaScript en el navegador.

## Cómo verlo

Abrir `index.html` con la extensión Live Server de VS Code.
No requiere instalar nada.

## Tecnologías

- HTML5 semántico
- CSS3 (variables y personalización de Bootstrap sin `!important`)
- Bootstrap 5.3 por CDN
- JavaScript (DOM, eventos, arrays)
- Git / GitLab
